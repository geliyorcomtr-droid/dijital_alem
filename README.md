# dijital alem — Ana Sayfa prototipi

Bu depo, **dijital alem** Ana Sayfa arayüzünün statik prototipini içerir.

## Çalıştırma

`index.html` dosyasını bir tarayıcıda açın veya basit bir yerel sunucu kullanın:

```bash
npx serve .
```

## İçerik

- `index.html` — sayfa yapısı
- `styles.css` — stiller
- `app.js` — etkileşimler
- `assets/` — görseller
